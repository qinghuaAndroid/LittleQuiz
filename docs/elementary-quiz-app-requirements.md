# 小学生 AI 问答应用需求

## 目标

构建一个面向小学生的轻量学习问答 MVP。每次专注一题，回答后立即给出温和、易懂的讲解；题目应覆盖数学、语文和英语，并可离线体验。

## 核心体验

- 单题页面明确分为题目、作答和 AI 讲解三个区域。
- 题目可为选择题或文字填空题，提交后立刻判断对错。
- 讲解要说明答案和简短解题思路，而不是只给分数。
- 只有显示讲解后，用户才能水平滑动进入下一题；切题时要有明显的页面过渡。
- 显示当前题目的学科标签，并轮换数学、语文、英语练习。
- 显示加载、失败和重试状态。讲解出现时预加载下一题，减少等待。

## AI 与数据边界

- MVP 必须在没有网络或外部 AI 服务时可用，使用本地题库/生成器作为回退。
- 题目生成通过 `QuizAiRepository` 抽象，未来可替换为安全后端实现。
- 不在客户端保存或提交任何模型 API Key；生产环境由后端保管凭据并返回已验证的题目结构。

## 技术约束

- 保持现有 Android XML Views、Kotlin、ViewBinding 和 AppCompat 技术栈，不使用 Compose。
- 使用生命周期安全的 Architecture Components 保存题目和 UI 状态。
